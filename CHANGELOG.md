# Changelog

## 1.0.0 (new @onpeek/nuvio package)

- Replaced the MCP server with a terminal CLI and a compact agent skill.
- Preserved the Nuvio account operations, snapshots, undo, and plans.
- Removed deprecated command aliases and remote MCP transports.
- Added JSON output limits and explicit file output for large results.
- Added persistent, single-use confirmation tokens for irreversible CLI operations.

The earlier nuvio-mcp release history remains in its original repository.
